Reporting Issues

If you encounter a bug or issue, please help us improve by reporting it. Here’s how:

1. Search Existing Issues: Look through open issues on GitHub to see if your issue is already reported.


2. Open a New Issue: If no similar issue exists, create a new issue. Include:

A clear and descriptive title.

Steps to reproduce the problem.

Expected and actual behavior.

Any relevant screenshots or logs.



3. Label the Issue: If possible, add labels to indicate if it’s a bug, enhancement, or documentation issue.



Visit our Issues Page to report issues.
